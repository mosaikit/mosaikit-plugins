# Sites

Publishes a static site from a zip archive. Sites are shared like any item, can have a public link, a thumbnail and a card view, and a language change follows the host. Links to outside sites live in Bookmarks; sites made by address with an earlier version stay here and can be downloaded for Bookmarks in one click.

Uses:
- Publishing a documentation site or a landing page prepared elsewhere
- Putting a report exported as static HTML next to your tools, with its own thumbnail
- Handing a customer a private preview of a site with a link
