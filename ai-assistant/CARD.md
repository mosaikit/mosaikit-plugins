# AI Assistant

A chat assistant for the whole platform. It reads your data, shows the KPIs, helps you configure the tenant and proposes the items to create in the apps; you confirm every change. It always works with your own rights, keeps your chats private and saved, opens as a side panel from the top bar, and offers the same tools to outside AI clients such as Claude Desktop through an MCP server with personal access tokens.

Uses:
- Asking how the tenant is doing (people, space, late tasks) and getting an answer from the real data
- Drafting a note, a task or a bookmark from a sentence and approving it before it is created
- Connecting Claude Desktop to the platform with a read-only token to query it from your own client
